09

RBI Weekly Dashboard

Live • Personal Project

The Reserve Bank of India publishes a new report as a raw spreadsheet every week — no history, no comparison. A scheduled job fetches each Friday's figures once the report lands (reserves, gold, the rupee against the dollar and euro, the main market indexes, crude-import estimates and FII flows, plus the World Bank's quarterly external-debt rankings) and commits whatever changed, so the dashboard shows what moved and by how much rather than one week in isolation. Trend lines and a searchable 10/26/52-week history, a tab that compares any two Fridays metric by metric, RBI MPC and Fed decisions annotated onto the rupee chart, an RSS feed of new weeks, and an installable build that still renders the last week it fetched when the network is down.

Node.jsGitHub ActionsCloudflare WorkersScrapersWorld Bank
Live Dashboard → GitHub → Project page →
10

CSNL Module Picker

Live • UCD

A module picker for UCD Computer Science students that builds a clash-free weekly timetable — and nothing about it is hardcoded. Class timings, offerings, module titles and the academic year are fetched live from UCD's General Reference Timetable on every load, and the module list comes from UCD's own CSNL page, re-read on every request and daily by a scheduled function, so new modules appear and retired ones disappear without a code change. Only the target year's timetable is ever served: when UCD has published the year but not the schedule, a module says it has no timetable rather than showing last year's times, and any module code can be added by hand.
