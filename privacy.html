What the site stores on your device

The site sets no cookies and writes no localStorage entries. It writes one sessionStorage key, ps-splash-seen, so the opening animation plays once per browser tab and is skipped on a repeat visit. That value stays in the tab, is readable only by this origin, and disappears when the tab closes.

There is no analytics script, no advertising pixel and no cross-site tracker on any page. The portfolio's own project pages use the same no-cookie setup.

Requests your browser makes

Some sections show live public data. Those reads are the only third-party requests the page makes, and none of them carries an account, a profile or a tracking identifier:

  • GitHub API (api.github.com) - public profile, repository and follower counts for the connect card. GitHub receives the request and the usual connection metadata.
  • This site's own Functions - /api/contributions returns the public GitHub contribution calendar and /api/medium returns the public Medium feed. Each Function fetches its source server-side and caches the answer, so your browser talks only to this origin.
  • Content Tracking Dashboard (contenttrackerdashboard.pages.dev) - the public watchlist rows behind the dashboard section's figures.
  • Self-hosted fonts and assets - served from this domain. No font CDN or icon CDN is contacted.

Following a link to LinkedIn, GitHub, Tableau Public, Medium, RxResu or a project's own site leaves this site, and that destination's privacy policy applies from then on.

Hosting and server logs

The site is hosted by Cloudflare Pages. Cloudflare processes the request needed to serve a page - including IP address, requested URL, user agent and timestamp - under its own privacy terms, and may keep security and operational logs. Parth does not run an analytics product over those logs, does not build visitor profiles from them and does not sell or share them.

Email

If you email soni.soni.parth@gmail.com, the message and your address are processed by the email provider (Gmail) so the message can be delivered and answered. They are used to reply to you and to keep a record of the conversation; they are not added to a marketing list and are not sold. Ask for a message to be deleted and it will be, unless a legal obligation requires it to be kept.

Your rights

Under the GDPR you can ask what personal data is held about you, ask for a copy, ask for it to be corrected or erased, or object to its processing. Because this site collects so little, the practical route for any request is email to soni.soni.parth@gmail.com. You also have the right to complain to the Irish Data Protection Commission (dataprotection.ie).

Changes

If this page changes, the date at the top changes with it. The site has no cookies to consent to, so there is no banner to dismiss.
